═══════════════════════════════════════════════════════════════════════════════
                              DATA FLOW EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

1. CREATE INCIDENT WITH VOICE
   ┌─────────────────────────────────────────────────────────────────┐
   │ User records audio → Frontend → POST /api/v1/speech/transcribe  │
   │ → Whisper Service → Returns transcript                          │
   │ → LLM Service parses → Returns structured data                  │
   │ → POST /api/v1/incidents → Create incident                     │
   │ → Notification Service → Send SMS & Email                       │
   │ → WebSocket broadcast "incident.created"                        │
   └─────────────────────────────────────────────────────────────────┘

2. AMBULANCE DISPATCH
   ┌─────────────────────────────────────────────────────────────────┐
   │ Coordinator approves plan → POST /api/v1/incidents/{id}/approve │
   │ → POST /api/v1/incidents/{id}/dispatch                          │
   │ → Ambulance Service finds nearest                               │
   │ → Hospital Service ranks & reserves bed                         │
   │ → Google Maps calculates route                                  │
   │ → Notification Service sends alerts                             │
   │ → WebSocket broadcasts:                                         │
   │   • "incident.dispatched"                                       │
   │   • "ambulance.assigned"                                        │
   │   • "hospital.bed_update"                                       │
   └─────────────────────────────────────────────────────────────────┘

3. REAL-TIME TRACKING
   ┌─────────────────────────────────────────────────────────────────┐
   │ Ambulance GPS updates → PATCH /api/v1/ambulances/{id}/location  │
   │ → Update database                                               │
   │ → WebSocket broadcast "ambulance.location_updated"              │
   │ → Frontend map updates marker (no page refresh)                 │
   └─────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════════
                            FALLBACK MECHANISMS
═══════════════════════════════════════════════════════════════════════════════

Google Maps ────(fails)───→ OSRM Routing
     │
     └──(geocoding fails)──→ Nominatim (OpenStreetMap)

SMS (Twilio) ───(fails)───→ Email (SendGrid)

OpenAI API ─────(timeout)──→ Rule-based fallback (if implemented)

═══════════════════════════════════════════════════════════════════════════════
                              SECURITY LAYERS
═══════════════════════════════════════════════════════════════════════════════

1. Authentication:  JWT tokens with automatic refresh
2. Authorization:   Role-based access control (RBAC)
3. Input:          Validation & sanitization (Pydantic)
4. API Security:   Rate limiting, CORS, HTTPS
5. Database:       SQL injection protection (ORM)
6. Secrets:        Environment variables, no hardcoding
7. Logging:        No sensitive data in logs
